# Ruscan

Утилита командной строки на языке C для проверки занятости доменных имён
второго уровня в зонах **.RU**, **.SU** и **.РФ** (`xn--p1ai`). Запрос идёт
в службу WHOIS национального реестра; сам проверяемый домен при этом не
разрешается и не опрашивается.

## Возможности

* Одно имя или список любого объёма — из аргументов, файла или стандартного
  ввода; комментарии (`#`), пустые строки и повторы отбрасываются.
* Три формата вывода: текст, CSV и JSON.
* Строгая проверка ввода: URL, чужие зоны, имена третьего уровня и кириллица
  вне punycode отклоняются с объяснением, а не додумываются.
* Предельный срок на запрос, повтор при сетевом сбое, пауза между
  обращениями и корректная остановка по `Ctrl+C`.

## Сборка

Зависимостей, кроме компилятора C11 и стандартной библиотеки POSIX, нет.

```sh
make            # сборка
make test       # автономные проверки, сеть не используется
make fmt lint   # форматирование и контроль стиля
make sanitize   # проверки под AddressSanitizer и UBSan
make install    # установка в /usr/local/bin (PREFIX переопределяется)
```

## Быстрый старт

```console
$ ruscan yandex.ru
yandex.ru                        REGISTERED

$ ruscan qwzx-probe-7391.ru
qwzx-probe-7391.ru               FREE
```

Вывод лаконичен: имя и вердикт. Подробности реестра выводит ключ `-v`.
Результаты идут в стандартный вывод, служебные сообщения — в поток ошибок,
поэтому перенаправление `> файл` даёт чистые данные.

## Массовая проверка

Список — по одному имени в строке; `#` начинает комментарий. Повторы
устраняются до начала опроса.

```sh
ruscan -f domains.txt                          # текстовый отчёт
ruscan -f domains.txt -F csv -o report.csv     # CSV в файл
ruscan -f - -F json < domains.txt > out.json   # чтение со стандартного ввода
```

Между запросами выдерживается пауза (по умолчанию 1000 мс, минимум 200 мс):
служба WHOIS ограничивает частоту обращений. Параллельных соединений
программа не открывает принципиально.

## Параметры

| Ключ | Назначение |
| --- | --- |
| `-f, --file PATH` | читать имена из файла; `-` означает стандартный ввод |
| `-o, --output PATH` | записать отчёт в файл вместо стандартного вывода |
| `-F, --format FMT` | `text` (по умолчанию), `csv` или `json` |
| `-d, --delay MS` | пауза между запросами (по умолчанию 1000, минимум 200) |
| `-t, --timeout MS` | предельный срок на один запрос (по умолчанию 15000) |
| `-r, --retries N` | число повторов после сетевого сбоя (по умолчанию 1) |
| `-s, --server HOST` | узел WHOIS из встроенного списка разрешённых |
| `-R, --raw` | вывести также обеззараженный исходный ответ (только `text`) |
| `-n, --dry-run` | проверить и очистить список, не обращаясь к сети |
| `-v, --verbose` | подробности по каждому имени; при перенаправлении — ход работы |
| `-q, --quiet` | полностью подавить поток ошибок |
| `-h, --help` / `-V, --version` | справка и версия |

## Статусы и коды возврата

| Статус | Значение |
| --- | --- |
| `FREE` | записи нет: имя свободно для регистрации |
| `REGISTERED` | имя зарегистрировано |
| `RESERVED` | имя в стоп-листе реестра, регистрация невозможна |
| `UNKNOWN` | ответ получен, но однозначного вывода не даёт |
| `FAILED` | имя не прошло проверку либо запрос не был выполнен |

Статус `UNKNOWN` намеренно не приводится ни к «свободно», ни к «занято».

Коды возврата: `0` — по каждому имени получен определённый ответ; `1` — ошибка
в параметрах; `2` — нет ни одного пригодного имени; `3` — есть `UNKNOWN` или
`FAILED`; `4` — выполнение прервано сигналом.

## Ограничения

* **Только второй уровень.** Для имени третьего уровня в публичной зоне
  (`msk.ru` и подобных) реестр не авторитетен, поэтому такие имена
  отклоняются, а не выдаются за свободные.
* **Интернационализированные имена — в форме punycode:** вместо `яндекс.рф`
  следует указать `xn--d1acpjx3f.xn--p1ai`. Молчаливая перекодировка внутри
  программы означала бы риск запросить не то имя.
* **WHOIS не аутентифицирован.** Обмен ведётся открытым текстом; подлинность
  ответа не подтверждается. Юридически значимые сведения следует получать у
  аккредитованного регистратора.
* **Свободный статус не является офертой:** действуют правила регистратуры,
  стоп-листы и преимущественные права.
